# 1. Classification Rules

- **REPORT UPDATE — CONTEXT-STABLE**: source-reconciled detail can be restored/strengthened without waiting for further solution design.
- **DEFER — SOLUTION-DEPENDENT**: the current report is incomplete, but wording should wait until the proposed physical solution is technically refined.
- **ALREADY ALIGNED / PRESERVE**: V0.5 correctly reflects the mature context or correctly omits an older overstatement.
- **EVIDENCE / APPENDIX ACTION**: affects evidence selection, plate population or appendix traceability.
- **VERIFICATION / QUALIFICATION ACTION**: affects measurement, uncertainty, design-development or close-out controls.

A Stage-A finding is not an instruction to reproduce historical wording verbatim. V0.6 should preserve the accepted softer engineering narrative and use the recovered source detail only where it materially improves technical understanding.

1. the V0.2-derived softer formal-engineering narrative voice;

7. the source-control-before-secondary-containment hierarchy;
8. the distinction between U4 and L3 causal strength;

14. event-driven trip/restart material being distinguishable from chronic source-generated spillage;
15. housekeeping being consequence control rather than a substitute for source correction;
16. standardising required engineering **function**, not blindly duplicating identical hardware;
17. conceptual drawings remaining non-fabrication documents requiring site/OEM/responsible-engineer development.
