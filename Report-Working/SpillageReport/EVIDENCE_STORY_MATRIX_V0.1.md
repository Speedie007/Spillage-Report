# South32 Wessels Spillage Audit — Evidence / Story Matrix V0.1

## Status
**PRELIMINARY COMPILER CLASSIFICATION — READY FOR INSPECTOR REVIEW**

This matrix is the first full evidence/story classification prepared after acceptance of `Running_Report_Contextual_Spillage_NotesV3.8.docx` and `REPORT_NARRATIVE_OUTLINE_V0.1.md`.

It covers **all 197 curated repository media items**. The source set was already reduced by the inspector from more than 700 original media items, so this first pass is deliberately conservative: **no item has been assigned `X — Exclude` yet**. Low-priority/redundant-but-still-useful material has been placed in `A — Appendix / Reference` rather than discarded. `X` should only be introduced after inspector review where an item is genuinely duplicative, weak, blurred or non-contributory.

The detailed sortable row-by-row matrix is stored in `EVIDENCE_STORY_MATRIX_V0.1.csv`.

## Inclusion Key
- **E — Essential body evidence:** required to prove a principal finding, mechanism, topology point or narrative conclusion.
- **S — Supporting / story evidence:** adds unique topology, sequence, extent, operating context, comparison, consequence or remedial-design context and should normally remain available to the body narrative.
- **A — Appendix / reference evidence:** useful traceability or alternate/context evidence that does not need to interrupt the main narrative.
- **X — Exclude:** intentionally unused in this preliminary pass; to be assigned only after inspector review.

## First-Pass Totals
- Total media: **197**
- Essential body (`E`): **80**
- Supporting/story (`S`): **92**
- Appendix/reference (`A`): **25**
- Exclude (`X`): **0**

This is not a prediction that 172 items will all appear in the final body. `E` and `S` define the **story-capable evidence pool**. Final placement will be controlled during evidence-module design, where some supporting items may move to appendices if the same technical point can be conveyed without losing topology, sequence or meaning.

## Review Method
For each item the CSV records: canonical ID, repository filename, prior visual-evidence strength, preliminary inclusion status, story-role tags, narrative theme, proposed report use, primary narrative section and the governing qualification/caution.

Recommended inspector review sequence:
1. Review **E items first** — confirm nothing important is missing from the essential set.
2. Review **A items second** — identify anything whose narrative purpose means it should be promoted to `S` or `E`.
3. Review **S items by asset/story** — identify genuine duplicates that may later become `A` or `X`.
4. Introduce `X` only where exclusion is clearly safe.
