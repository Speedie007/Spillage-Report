# South32 Wessels Combined Product Spillage Audit — Appendix D Draft V0.1

## Status
**PASS 7E — REPORT-READY TECHNICAL BACKBONE DRAFT**

## Purpose
Appendix D is the report-facing measurements / verification register derived from the controlled Pass 7C source:

`PHASE7_VERIFICATION_SUCCESS_CRITERIA_REGISTER_V0.1.md`

It identifies what still has to be measured, inspected, observed or formally assessed before major recommendations can proceed through design, implementation and functional close-out.

No unknown dimension, tolerance, structural capacity, feed rate, OEM criterion or monitoring duration is invented here.

## Verification classes
- **M** — measured geometry / dimensional verification
- **O** — representative operating verification
- **D** — design-development input
- **S** — competent structural assessment
- **P** — pilot / performance monitoring
- **C** — procedure / governance verification
- **A** — wider applicability review

## Verification gates
- **G1** — required before detailed design / final solution selection
- **G2** — required before implementation / repair acceptance
- **G3** — required before final functional close-out
- **G4** — required before wider rollout / standardisation

## Functional close-out rule
The governing close-out sequence remains:

> **As-found evidence → verification / measurement → corrective design or control → implementation → representative operating proof → as-left record → monitoring / closure.**

A completed maintenance task, installed component, cleaned area or conceptual drawing does not by itself prove functional closure.

## Authority boundary
Where final tolerances, structural capacity, OEM limits, feed-control basis, monitoring duration or acceptable operating criteria are required, those remain South32 / responsible-engineer / OEM / competent-person decisions based on verified conditions and applicable requirements.
