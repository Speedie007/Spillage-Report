Appendix E controls the conceptual engineering figures currently available for the report.

These figures communicate the intended engineering principle. They are **not final technical designs, fabrication drawings or approved site geometry**. Detailed technical refinement is intentionally deferred until the assembled report has been reviewed in context and the responsible engineer has had the opportunity to comment on the concepts.

All applicable figures should retain a visible qualification such as:

> **CONCEPTUAL ONLY — NOT FOR FABRICATION — DIMENSIONS TO BE VERIFIED ON SITE**

3. These file-control issues are **not report-development blockers** because the controlled report references `CTD-001` through `CTD-004` are unambiguous.
4. Final drawing filename/ID normalisation should occur after engineer conceptual review and before controlled publication.
5. The figures are **report-support engineering concepts**, not inspection evidence; they are not included in the 197 inspection-media total.

## Technical refinement hold point
Final refinement is deliberately sequenced as:

> **complete assembled report → engineer conceptual review → record requested technical changes → obtain/confirm site geometry where required → refine drawings → normalise final drawing IDs/filenames → approve report-ready final figures**

This avoids spending design effort on graphics before the full report context and responsible-engineer review are available.
