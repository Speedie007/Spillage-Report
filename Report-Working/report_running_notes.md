## Governing Engineering Message
> **Keep the combined product — fines and coarse/lump ore — within the intended process/material-handling envelope throughout transit, using the control mechanism appropriate to the failure mode and local geometry.**

The report must also retain the principle that **the point where material is found is not necessarily the point where the initiating failure occurred**.

## High-Level Audit Model
The audit is qualitative and mechanism-focused. It identifies three recurring material-loss families plus one event-driven operating mechanism:
1. fines / carryback;
2. coarse or mixed combined-product loss during transit;
3. water-related escape / wet fines / slurry;
4. event-driven trip/restart unloading.

The mine does not have one isolated spillage defect. It has a connected set of material-containment weaknesses requiring one common control philosophy with several different physical solutions.

## Key System / Case Logic
### Fines / Cleaner-Containment
- CV06 = cleaner function lost through mechanical/maintenance condition.
- CV09 = material is removed from the belt but not adequately retained within the intended process envelope.
- CV09 remains the preferred pilot for a functional cleaner/containment philosophy.
- If successful, standardise the **required function**, not identical hardware, after local geometry/access/applicability checks.
- U4 remains a geometry-specific exception requiring separate assessment.

### Coarse / Combined Product
- W10 is a key coarse-product containment case in a confined tunnel; the exact initiating cause of every deposit remains unresolved, but the breach of the carrying envelope and access consequence are clear.
- A local Conveyor Side-Containment Barrier / Side-Containment Rail / Side-Containment System remains a secondary remedial concept subject to dimensional/tracking/clearance/structure verification.
- Sample Conveyors 2/3 remain a feed/load-versus-usable-belt-width problem first, tracking/tension problem second, and secondary side-containment problem third.
- Sample Conveyor 2 mistracking remains unconfirmed; Sample Conveyor 3 mistracking is visually supported but unmeasured.

### Alignment / Water / Structural / Operational
- U4 mistracking and one-side product loss are visually verified; tail-pulley misalignment remains inspector-recorded/visually supported but unquantified.
- L3 tail-end offset is supported; a direct causal chain to significant solid-product loss remains unconfirmed.
- Screens: water loss of containment is directly verified; equipment-level source remains unresolved. Cut/notched supports and severe deterioration require separate structural assessment.
- L1: historical/intermittent belt contact is supported by wear slots; continuous present contact is not proven. Concrete/steel deterioration is a separate structural issue.
- Housekeeping controls the consequence; source control should reduce recurrence.
- Trip/restart clearing remains a separate event-driven mechanism requiring confirmation of formal unloading, laydown, recovery and reintroduction procedures.
